# Kenya Population Choropleth — STARTER

Geo Intelligence Lab · Video 2 · code-along starting point

Already done for you: Vite + React + TypeScript project, Mapbox GL JS installed, the prepared county GeoJSON in `public/data/`, styles, the info panel, and a map centred on Kenya.

You will build, following the video:

1. Add the county GeoJSON source (`promoteId`)
2. Colour counties with a `step` expression
3. Draw county borders
4. Hover highlight with `feature-state`
5. Toggle between density and population
6. Build the legend

## Run it

```bash
npm install
cp .env.example .env   # paste your Mapbox public token (pk.…)
npm run dev
```

The finished code is in the `final` folder.
